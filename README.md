# Полка — гардероб обуви

Веб-приложение для учёта обуви: название, бренд, описание, сезонность, размер,
цвет и фотография. Бэкенд на фреймворке [Polka](https://github.com/lukeed/polka)
с базой данных SQLite; фотографии сохраняются через сменного провайдера
хранилища (по умолчанию — локальный диск сервера).

## Требования

- Node.js версии не ниже 22 (см. поле `engines` в `package.json`).
- npm (поставляется с Node).

## Установка и запуск локально

```bash
git clone https://github.com/hollyfox2026-lab/polkafox.git
cd polkafox
git checkout cursor/polka-wardrobe-ce6c
npm install
npm run dev
```

Приложение откроется на `http://localhost:3000`.

## Скрипты

| Команда             | Назначение                                   |
| ------------------- | -------------------------------------------- |
| `npm run dev`       | Сервер разработки с автоперезапуском.         |
| `npm run build`     | Компиляция TypeScript в `dist/`.              |
| `npm start`         | Запуск собранного сервера из `dist/`.         |

## База данных

Используется SQLite — встраиваемая база данных. Отдельный сервер устанавливать
не нужно: движок подключается npm-пакетом `better-sqlite3`, а сама база — это
файл `data/polka.db`, который создаётся при первом запуске. Файл лежит на той
машине, где работает бэкенд (при локальной разработке — на Вашем компьютере).
Путь можно переопределить переменной `DB_PATH`.

Для доступа к данным с нескольких устройств бэкенд с этим файлом должен работать
на общем сервере, а не только на личном компьютере.

## Хранилище фотографий

Провайдер выбирается переменной `STORAGE_PROVIDER`:

- `local` (по умолчанию) — файлы сохраняются в каталог `uploads/` и раздаются по
  адресу `/uploads/...`. Внешних учётных записей не требуется.
- `yandex` — облачное хранилище Yandex. Подключается на следующем шаге после
  выбора варианта (Object Storage или Диск) и добавления ключей доступа.

Интерфейс `StorageProvider` (`src/storage.ts`) единый, поэтому смена провайдера
не затрагивает остальной код.

## API

| Метод  | Путь               | Назначение                                  |
| ------ | ------------------ | ------------------------------------------- |
| GET    | `/api/health`      | Проверка состояния и активного хранилища.   |
| GET    | `/api/seasons`     | Список допустимых сезонов.                   |
| GET    | `/api/shoes`       | Список пар; фильтры `?season=` и `?q=`.      |
| GET    | `/api/shoes/:id`   | Одна пара.                                   |
| POST   | `/api/shoes`       | Добавить пару (multipart с полем `photo`).   |
| DELETE | `/api/shoes/:id`   | Удалить пару и её фотографию.                |

## Структура проекта

```
src/        Бэкенд: конфигурация, БД, хранилище, API, сервер
public/     Фронтенд (HTML/CSS/JS)
test/       Тесты Vitest
data/       Файл базы данных SQLite (создаётся при запуске, в git не хранится)
uploads/    Локально сохранённые фото (создаётся при запуске, в git не хранится)
```
