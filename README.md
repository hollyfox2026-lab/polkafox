# Полка

Веб-приложение учёта обуви: карточки с фотографией, размером, сезоном, типом и описанием.

Публикация: GitHub Pages, адрес https://hollyfox2026-lab.github.io/polkafox/.
Ветка публикации — `gh-pages`. Исходный код — ветка `main`.

## Состав

Приложение выполняется в браузере. Серверная часть не требуется.

- Каталог и фотографии хранятся локально в IndexedDB.
- При входе через Яндекс каталог записывается в папку приложения на Яндекс Диске и читается с Диска на любом устройстве.
- Без входа используется только локальная копия.

## Требования

- Node.js версии не ниже 22.
- npm.

## Локальный запуск

```bash
npm install
npm run dev
```

Адрес разработки: http://localhost:5173.

Вход через Яндекс завершается только на зарегистрированном Redirect URI:

`https://hollyfox2026-lab.github.io/polkafox/`

Локальный сервер сохраняет карточки в IndexedDB без обмена с Диском, пока сессия Яндекса не получена на опубликованном адресе.

## Синхронизация с Яндекс Диском

OAuth-приложение:

- ClientID: `f0970ad906314eaa83edca91ff565e3d`
- Redirect URI: `https://hollyfox2026-lab.github.io/polkafox/`
- Право: `cloud_api:disk.app_folder` (допускается чтение и запись Диска, если так задано в кабинете)

После выдачи токена приложение:

1. Создаёт каталог `app:/polka` (при отсутствии права на папку приложения — `disk:/Полка`).
2. Читает файл `catalog.json`.
3. Объединяет его с локальной копией по полю `updatedAt`.
4. Записывает объединённый каталог обратно на Диск, включая фотографии в формате JPEG data URL.

Удаление карточки помечается в каталоге и переносится на другие устройства.

Токен хранится в `localStorage` браузера. Клиентский секрет OAuth в коде отсутствует.

## Публикация

При доставке в `main` GitHub Actions собирает сайт и обновляет ветку `gh-pages`.

Ручная публикация:

```bash
npm run build
```

Содержимое каталога `dist/` размещается в корне ветки `gh-pages`.
